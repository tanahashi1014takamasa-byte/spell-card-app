① 変更内容を保存

② ターミナルでプロジェクトフォルダを開く

③ GitHubへ反映

【Vercel デプロイ時の表示】

● Building...
ビルド中。完了するまで待つ。

● Ready
デプロイ成功。サイト公開完了。

● Error
デプロイ失敗。ログを確認して原因を修正する。

● Queued
デプロイ待機中。

● Canceled
デプロイがキャンセルされた。

● Deploying
公開処理中。

● Production
現在公開中の最新バージョン。

● Preview
プレビュー用デプロイ。動作確認用。

● Commit
GitHubへ送信したコミット。

● Build Logs
ビルドの詳細ログ。エラー原因を確認できる。

● Functions
サーバー側処理のログ。

● Source
デプロイ元のGitHubリポジトリ。

● Duration
ビルドにかかった時間。

● Inspect
デプロイ内容やログの詳細を確認する。


【PWA（Progressive Web App）について】
・概要

本アプリでは、Webアプリケーションをスマートフォン向けアプリのように利用できるようにする技術として、PWA（Progressive Web App）を採用した。

PWAとは、Web技術を利用して開発されたアプリケーションに、ネイティブアプリに近い操作性や機能を付加する仕組みである。App StoreやGoogle Playからインストールする一般的なアプリとは異なり、Webブラウザからアクセスし、ホーム画面へ追加することでアプリケーションのように利用できる。

・導入目的

本アプリでは、ユーザーが手軽にゲームへアクセスできる環境を構築することを目的としてPWA化を行った。

従来のWebアプリでは、利用時にブラウザを開いてURLへアクセスする必要がある。しかしPWAを導入することで、スマートフォンのホーム画面上に専用アイコンを配置し、通常のアプリと同じような感覚で起動できる。


・実装内容

PWA化では以下の設定を行った。

1. アプリアイコンの設定

スマートフォンのホーム画面に表示するアイコンとして、192×192pxおよび512×512pxの画像を用意した。

これらのアイコンをmanifest.jsonで指定することで、端末に適したサイズのアイコンが使用される。

2. Web App Manifestの設定

manifest.jsonを作成し、アプリケーション名、アイコン、起動方法などを定義した。

主な設定項目は以下の通りである。

name：アプリケーションの正式名称
short_name：ホーム画面などで表示される短縮名称
icons：アプリアイコンの指定
start_url：起動時に表示するページ
display：表示形式

特にdisplayをstandaloneに設定することで、ブラウザのURLバーを表示せず、独立したアプリケーションのような画面で起動できるようにした。

3. Next.jsへの統合

Next.jsのlayout.tsxにmanifestの読み込み設定とアイコン情報を追加し、WebアプリケーションとPWA設定を連携させた。

これにより、Next.jsで構築したゲームシステムをそのままPWAとして利用可能にした。

PWA導入による効果

PWA化によって、本アプリは以下の特徴を持つようになった。

スマートフォンのホーム画面から直接起動可能
iPhone、Androidの両方で利用可能
アプリストアを経由せず配布可能
Webアプリの更新を即時反映可能
既存のNext.js開発環境を維持したままアプリ形式へ対応可能
今後の拡張

PWAにはキャッシュ機能を利用したオフライン動作や、プッシュ通知などの機能も存在する。

今後、ゲームデータや画像素材をキャッシュすることで、通信環境に左右されにくいゲーム体験を提供することも可能である。

今回のPWA導入により、本アプリはWeb技術を基盤としながら、ユーザー視点ではスマートフォンアプリに近い操作性を持つゲームシステムへ発展した。
